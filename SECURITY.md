# Seguridad

Proyecto educativo para uso **exclusivamente local**. No está diseñado para producción ni para operar con dinero real.

- No publiques este proyecto con credenciales reales.
- Las credenciales de `.env.example` son valores locales de ejemplo.
- El JWT se guarda en `localStorage` como decisión de demo local; no es una arquitectura de producción.
- Los precios y la evolución de la cuenta son **datos sintéticos**.
- Este proyecto no constituye asesoramiento financiero.

Si encuentras una vulnerabilidad, abre una issue sin incluir datos personales ni secretos.
